# anuragbansalvips.github.io

Personal website and portfolio of Anurag Bansal, hosted at [anuragbansal.me](https://anuragbansal.me).

## 🌐 Live Site

Visit the site at: **[https://anuragbansal.me](https://anuragbansal.me)**

## 📖 About

This is a GitHub Pages-hosted personal website. The custom domain `anuragbansal.me` is configured via the `CNAME` file.

## 🚀 Deployment

This site is automatically deployed via [GitHub Pages](https://pages.github.com/) from the `main` branch.

Any push to `main` triggers a new deployment.

## 🛠️ Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/anuragbansalvips/anuragbansalvips.github.io.git
   ```

2. Open `index.html` (or the main entry point) in your browser to preview locally.
