## 🔧 Setup & Deployment

This site is powered by **[GitHub Pages](https://pages.github.com/)** and served through a custom domain.

### Custom Domain
The site uses the custom domain `anuragbansal.me` configured via the `CNAME` file. GitHub Pages automatically handles the routing and HTTPS certificate.

### Local Development
```bash
# Clone the repository
git clone https://github.com/anuragbansalvips/anuragbansalvips.github.io.git

# Navigate into the directory
cd anuragbansalvips.github.io

# Open in your browser or use a local server
# e.g., with VS Code Live Server or Python's built-in HTTP server
python -m http.server 8000
```
